# STaR 为什么相当于只在答对样本上做策略梯度

[RSI 闭环原理与护栏](../nodes/node-rsi-notes.md)

掌握度：未测

## 题眼 / 触发条件

- 题目提到自训练、拒绝采样微调（RFT）、ReST、Expert Iteration
- 问「只用答对的数据做 SFT，和强化学习有什么关系」

## 破题固定步骤 / 核心公式

- 1. 写出目标：最大化答对率 J = E[1(ŷ = y)]。
- 2. 用对数导数技巧求梯度：∇J = E[1(ŷ = y) · ∇ log p(r̂, ŷ | x)]。
- 3. 指示函数让答错样本梯度为 0，等价于只在答对样本上最大化似然。
- 4. 补充两点：Rationalization 解决难题没有信号的问题；每轮从初始模型重训，防止过拟合。

## 典型题与参考实现

证明 STaR「筛出答对样本再 SFT」是对答对率目标的策略梯度估计，并说明它和 PPO、GRPO 相比少了什么。

J(θ) = Σ_i E_{(r̂, ŷ) ~ p_θ(·|x_i)} [1(ŷ_i = y_i)]
∇J = Σ_i E[1(ŷ_i = y_i) · ∇ log p_θ(r̂_i, ŷ_i | x_i)]
用采样估计期望：答对样本权重为 1，答错为 0，正好是在答对样本上做最大似然。

相比 PPO / GRPO 少了：
- 负样本信号：答错的样本不提供往反方向推的梯度；
- 基线和优势：所有答对样本权重相同，不区分难题答对和简单题答对；
- 偏移约束：整轮采样后离线训练，没有 KL 或 clip 限制策略变化。

## 持续追加的变式与连环追问

### 变式 1：ReST-EM 和 STaR 有什么不同？
- 追问：ReST-EM 用 EM 的视角解释同一类方法，它在训练起点和数据构造上和 STaR 有什么不同？
- 关键变化：ReST-EM 同样每轮从基座模型重训，但不做 Rationalization，靠每题多次采样来覆盖难题。
- 解析：E 步：采样并按二值奖励过滤；M 步：在过滤后的数据上微调。
